航拍作業篇

Pack 01 教你認識隻機,Pack 02 教你飛得起,Pack 03 教你出事點算 —— 呢個 pack 教你「做嘢」:有客戶、有 deadline、有錢銀關係嘅真任務。八課跟住任務流程行:接單 → 評估 → 勘察 → 規劃 → 執行 → 收工 → 交付。

「攞唔到個鏡頭」永遠好過「出事」。出咗事,冇人會記得你差啲攞到個鏡頭;個個都會記得你炒咗機。

Lesson 01

任務同練習嘅分別 — 壓力下點守紀律

學完呢課你識做咩講得出任務同練習嘅三大分別;遇到「客戶催你」識用標準句式守住安全決定;明白總綱:「攞唔到個鏡頭」永遠好過「出事」。

練習好似排練,任務好似演唱會 live —— 歌一樣、樂器一樣,但 live 有觀眾、有時間表、唱錯冇得嚟過。三大分別:①有客戶(有人畀錢、有期望、喺你隔籬睇住你飛);②有 deadline(日落唔等人、場地租到六點);③環境唔係你揀(場地同時間好多時係客戶定)。

壓力點樣令好機師做錯事

民航界有個詞叫 get-there-itis(去到病) —— 機師因為「一定要準時到」而落錯決定,係好多空難嘅根源。航拍版就係「攞鏡頭病」:「差少少就攞到喇……電量低咗少少啫……再飛近少少啫……」每個「少少」單獨睇好似冇事,加埋就係 Pack 03 教過嘅 incident(事故)。壓力唔會令你技術變差,壓力會令你跳步驟 —— 跳 checklist、跳口令、跳起飛前 60 秒三問。

守紀律嘅方法

  • Checklist 同口令唔係新手輔助,係壓力下嘅自動導航 —— 大腦亂嗰陣,程序幫你諗。
  • 團隊口令一個字都唔改,而且係一問一答:清場企位 → 嗌「Taking off!」→ 聽到「CLEAR」 → 先 arm → 起飛;降落喺離地 10–20 米嗌「Landing!」→ 聽到「CLEAR」 → 先繼續落。有客戶喺場一樣照嗌 —— 呢啲嗌聲仲會令客戶覺得你哋專業。
  • 預先定好今日嘅放棄條件(電量到 X、風到 Y、人流到 Z 就收)🔧 具體數字由負責人定 —— 事前定好,現場先唔會同自己講數。

守住決定嘅三段式句式

  1. 同理:「我明呢個鏡頭好緊要。」
  2. 講原因(安全,唔係技術):「而家電量 / 風況去到我哋嘅安全線,再飛係有真風險。」
  3. 畀替代方案:「我哋可以聽日同一時段補拍 / 用另一個角度攞到差唔多效果。」

記住:講「做唔到」唔專業,講「做唔到,不過可以咁樣」先係專業。

練習目標 + 完成標準 🔧 施壓情境由負責人按真實接過嘅單調整

兩人一組角色扮演:一人扮客戶連續施壓三次(趕時間、加鏡頭、叫你飛近啲),一人扮 PIC 用三段式回應。完成標準:三次都守住決定、句式齊三段,由第三位隊員評分。

⚠️ 安全重點

任何人都冇權推翻安全決定 —— 包括客戶。PIC 有 final say(最終話事權)。VLOS、日光操作、暴雨警告(黃 / 紅 / 黑)、熱帶氣旋警告、強烈季候風信號生效時唔飛係法規,唔係隊規。出咗事,冇人會記得你差啲攞到個鏡頭。

Lesson 02

接單同任務評估 — 接單嗰刻已經係安全決定

學完呢課你識做咩攞到查詢識問齊「評估五問」先答應;識用地圖 + eSUA 做初步場地同空域檢查;講得出邊啲因素令任務變難。

點解評估係安全問題,唔係生意問題:接咗單先發現飛唔到,你就會企喺現場面對俾咗錢嘅客戶,同一個「唔飛就蝕」嘅壓力 —— 即係課 1 嘅壓力鍋。評估做得好,任務日就冇驚喜;評估求其,任務日就係補鑊。

評估五問

  1. 客戶想要咩?唔好收「幫我影靚啲」呢種柯打 —— 要 reference(參考片),再夾實 deliverable(交付物):幾多條、幾長、相定片、橫定直、幾時交。Reference 係翻譯機:客戶講「有 feel」,你要譯做「日落逆光 + 慢 orbit」。
  2. 場地喺邊、有咩限制?地圖先行:衛星圖睇障礙物同起降位,再查空域。地圖過到關,先安排實地 site survey(課 3)。
  3. 空域同法規過唔過到?依據係 Cap. 448G(《小型無人機令》),主管機構 CAD(民航處),平台 eSUA。已核實硬數字(Pack 01):A2 標準操作高度上限 300 呎、必須 VLOS、日光操作、暴雨警告(黃 / 紅 / 黑)、熱帶氣旋警告、強烈季候風信號生效時唔飛。空域限制同要唔要額外申請 —— 唔好靠記憶,以 CAD 官網同 eSUA 實時資料為準。商業操作有冇額外要求(保險、操作員等級):團隊持有第三者責任年保,保單由負責人持有。每單商業任務開工前要確認三樣:①保單仍然有效;②保額覆蓋今次操作類別(法定最低保額見 Pack 01 第 6 課);③任務地點喺保障範圍內。未確認保險之前唔准開工。
  4. 場地許可攞咗未?私人地方要業主 / 管理處同意;邊個負責攞、幾時攞到,白紙黑字問清楚。攞許可嘅時間好多時長過你想像。
  5. 時間窗夾唔夾?客戶要日落 golden hour(黃金時段),你要倒推幾點 setup、幾點 brief;天氣唔得有冇 backup day(後備日)。冇 backup day 嘅單 = 壓力加倍。

邊啲嘢影響難度(報價唔教,但你要識標記)

場地複雜(多障礙 / 多人流 / 訊號差)、要等審批、特殊鏡頭(跟拍 / 低飛 / 室內)、冇 backup day 嘅死線、夜景要求(直接觸法規紅線 —— 日光操作!)。見到呢啲,喺評估紀錄標返出嚟畀負責人。

Lesson 03

場地勘察 Site Survey — 地圖睇唔到嘅嘢

學完呢課你識做咩講得出 site survey(場地勘察)六大檢查範疇;識用 checklist 行一次現場,產出一頁紙紀錄;識揀 LZ(起降區)同預留 escape route(逃生空間)。

點解一定要去現場:地圖係舊嘅,現場係新嘅。地圖睇唔到:琴日先搭起嘅棚架、細過一粒 pixel 嘅電線、下晝先出現嘅人流、訊號黑點。Site survey 好似搬屋前去度尺 —— 冇人會靠平面圖就買晒啲傢俬。

六大檢查範疇

  1. 障礙物 —— 電線同拉索係航拍頭號殺手,天空背景下幾乎睇唔到。逐樣搵:電線、棚架、天線、旗杆、樹(樹會擺動)。搵到就影相 + 地圖標位。
  2. 人流時段 —— 呢個場幾點多人?目的係揀一個人流最少嘅拍攝時段,唔係諗住「到時避開」。
  3. LZ 起降區 —— 要平、冇沙石雜物(升起會吹到周圍都係)、同人流有距離、PIC 企嘅位睇得穿成條航線(VLOS!)。最好有後備 LZ 一個。
  4. Escape route 逃生空間 —— 問自己:「如果隻機而家出事,佢跌落邊度唔會傷人?」每段航線都要有答案(海面、空地得;人群、馬路、玻璃幕牆唔得)。同 Pack 03 應急思維直接駁通:出事嗰刻先諗就太遲。
  5. 訊號環境 —— 高壓電塔、天台發射站、大型金屬 = EMI(電磁干擾)風險。有懷疑就寫低,任務日預留 ATTI(姿態模式)心理準備(Pack 03)。
  6. 日照方向 —— 一係鏡頭(golden hour 嘅金色光係客戶至愛),一係安全:望住太陽方向飛 = 眩光 = VLOS 斷。用太陽位置 app 查返拍攝時段太陽喺邊。

產出物:一頁紙,六範疇每個有結論 + 相 + 標記,最後三格:建議拍攝時段、LZ 主 / 備、成隊人要知嘅危險。Survey 搵到嘅危險唔係心裡有數就算 —— 要寫低、要喺任務日 brief 講出嚟。🔧 checklist 細節數字由負責人調整

Lesson 04

航線同鏡頭規劃 — 鏡頭語言 + 風險評估

學完呢課你識做咩講得出五種基本航拍鏡頭嘅效果同各自風險;識砌一張 shot list(分鏡表),每個鏡頭有風險註記;識用慳電原則排拍攝順序。

鏡頭語言:五個基本盤

鏡頭效果風險評估
Push-in 推鏡向主體飛埋去,「聚焦、迫近」感你正向障礙物飛緊 —— 預先定「停止線」,幾近就唔再近 🔧
Pull-out 拉鏡由主體向後飛開,由細節揭開大環境機尾向前行 = 盲飛 —— 必須有 spotter 睇後路,或者先向後飛一次探路
Orbit 環繞圍住 POI(興趣點)轉圈轉到半圈變 nose-in(機頭向自己 —— Pack 02 第 5 課,左右倒轉)最易亂;成個圈 360° 都要淨空
Tracking 跟拍跟住移動主體(人 / 車 / 船)注意力全落主體,唔記得睇前路 —— 航線事先行一次,spotter 睇路
Reveal 揭示升高 / 越過遮擋物「揭開」場景記住 300 呎上限(Pack 01)+ 高空風大過地面;越障要預足淨空

一個實用組合:Reveal 開場 → orbit 交代環境 → push-in 收結 —— 好多樓盤片、活動片都係咁砌。

Shot list 分鏡表

好似購物清單:冇 list 就亂買,冇 shot list 就亂飛、嘥電、漏鏡頭。每行五格:鏡頭號 | 內容 | 位置 / 高度 | 難度 | 風險註記 + escape route。「呢鏡冇風險」都要寫,證明你諗過。任務前交負責人過目(以下任何一項中,shot list 就一定要交負責人審:①首次去該場地;②新客戶;③shot list 入面有風險註記;④需要 AOP 或者特別許可。熟客、熟場、小單 —— PIC 自己決定。⚠️ 但「熟唔熟」係你自己判嘅 —— 拿唔準就當唔熟,交審。)。

慳電原則:排拍攝順序

  1. Must-have(必要)先,nice-to-have(有更好)後 —— 電出意外淨返一嚿,起碼必要鏡頭到手
  2. 同位置同高度嘅鏡頭一齊拍 —— 慳往返同重新爬升嘅電
  3. 難鏡頭排喺頭嗰一兩嚿電 —— 人最精神、電最足、日光最穩定嗰陣做最難嘅嘢
  4. 每嚿電留 buffer(餘量)先返航 🔧 百分比由負責人定,參考 Pack 03 低電課

    ⚠️ 安全重點

    每個鏡頭 plan 埋 escape route。拉鏡冇 spotter 唔准做 —— 機尾冇眼。規劃嗰陣覺得「呢個鏡頭好牽強」,任務日佢只會更牽強 —— 喺紙上刪咗佢,好過喺天上搏。

    PIC飛。負全責,有 final say飛緊嗰陣唔同任何人傾偈 —— 包括客戶
    Spotter睇空域、障礙、圍觀者,同 PIC 講短句報告眼喺天上同四周,唔係喺 screen
    Client liaison(客戶聯絡)企喺客戶隔籬,答問題、擋查詢、傳達要求客戶所有嘢經佢,唔准直接埋 PIC 身

    點解要分?因為人腦一次只做到一樣嘢做得好。PIC 一路飛一路答問題,就係 Pack 02 講嘅 orientation(方向感)蝦碌高危狀態。人手唔夠三個點算:硬底線:最低 2 人 —— PIC(飛)+ spotter(睇)。不足三人就由 spotter 兼客戶聯絡,但佢見到危險可以隨時轉返全職監看(客戶等得,部機等唔得)。⚠️ PIC 永遠唔准兼任何其他角色 —— 一路飛一路答問題,就係 Pack 02 講嘅 orientation 高危狀態。 🔧,但底線係:PIC 飛緊嗰陣,一定有另一個人負責同客戶講嘢。

    現場 brief:五分鐘六格

    1. 今日拍咩(shot list 過一次)
    2. 飛邊度、幾高、LZ 喺邊
    3. 危險位(課 3 survey 嘅發現,現場再核實)
    4. 緊急程序:出事邊個做咩、escape route 喺邊(Pack 03 預案思維)
    5. 口令提一提:「Taking off!」→ 等「CLEAR」→ 先 arm;「Landing!」喺離地 10–20 米 → 等「CLEAR」→ 先落
    6. 分工確認:邊個 PIC、邊個 spotter、邊個湊客戶

    圍觀者管理 + 客戶期望

    • 預防:LZ 圍好 / 擺明顯標記,spotter 企喺人流方向。有人埋嚟:spotter 或 liaison 去處理,PIC 唔分心。
    • 有人衝入 LZ 或航線下方:即刻 hold(懸停)或 go-around(重新入場,Pack 02),人清咗先繼續。唔准邊飛邊嗌交。態度:圍觀者唔係敵人,係未來嘅客戶 —— 有禮但企硬。
    • 「可唔可以飛低啲 / 近啲?」→「呢個距離係安全要求。我哋可以用 zoom / 後期裁,效果好接近。」
    • 「隔籬條街好靚,順便影埋?」→ 唔喺 shot list、未 survey、未查空域 = 唔飛。「今日資料唔夠唔可以即興飛,不過可以幫你安排補拍。」講完做唔到,記得話返做到啲咩。

    ⚠️ 安全重點

    PIC 飛緊 = 唔對話。有嘢要話俾 PIC 知,經 spotter 用短句。客戶要求 vs 安全,安全贏,冇得傾 —— 呢句喺 brief 預先同客戶講咗,現場就唔使拗。即興加鏡頭 = 未評估嘅飛行 = 唔做。

    Lesson 06

    相機基本設定概念 — 識個道理,設定按機型

    學完呢課你識做咩講得出解像度同幀率嘅取捨邏輯,識由 deliverable(交付物)倒推設定方向;解釋到 ND filter(減光鏡)係咩、幾時用;分得清曝光三個元素。

    呢課只教概念 —— 團隊各人機型唔同,所有實際數字同選單位置 🔧 由負責人按機型出速查表:實際數字同選單位置逐機型唔同 —— 開工前問 PIC / 負責人,或者查返該機型說明書。呢課只教你識睇個數字係咩意思,唔係要你背數字。

    • 解像度 vs 幀率:一條數兩樣嘢爭。好多時要二揀一:要最靚畫質(高解像度)定要慢動作(高 fps)?答案唔喺相機度,喺 deliverable 度 —— 客戶要大螢幕播 → 解像度優先;reference 有慢鏡 → 嗰啲鏡頭要高 fps;唔知?課 2 應該問咗。
    • ND filter:相機嘅太陽眼鏡。影片想畫面「順滑有電影感」,快門要慢(概念叫 180° rule:快門大約係幀率兩倍嘅倒數,例如 30fps 用 1/60 —— 概念參考,唔使背)。但大太陽下慢快門會全白過曝 —— 所以要「戴太陽眼鏡」減光。日光影片任務,ND filter 係基本裝備,出門前 check 有冇帶。
    • 曝光三寶:ISO(感光度 —— 扭大會光啲但多雜訊,原則儘量低)、aperture(光圈 —— 好多航拍機係固定,得個知字)、shutter(快門 —— 影片影響 motion blur,影相影響郁嘅嘢清唔清)。
    • 影相 vs 影片:影相可以 RAW,後期執光暗空間大;影片後期補救空間細好多,現場要對 —— 所以影片任務先咁緊張 ND 同曝光。同一單任務兩樣都要?Shot list 標明邊啲相邊啲片,唔好飛到半路先諗。
    🎮 互動練習 · 客戶要咩 → 你點校
    客戶要求彈出 —— 揀設定方向。
    撳「開始」接客
    練習目標 + 完成標準 🔧 時限同機型由負責人定

    負責人畀三個模擬 deliverable(大螢幕形象片 / IG 慢鏡 / 平面相),逐個寫出設定方向 + 一句理由;之後喺地面用自己機型跟速查表校一次。完成標準:三個 case 方向啱 + 理由講得出;地面 3 分鐘內校齊。

    ⚠️ 安全重點

    校相機唔准飛緊校。起飛前校好,或者落地先校 —— 飛緊撳 screen = VLOS 斷。眼嘅優先次序:天上隻機 > 四周環境 > screen。唔記得帶 ND?照計劃用安全設定拍,唔好現場邊飛邊試。

    Lesson 07

    收工程序 — 素材 Check 咗先走!

    學完呢課你識做咩落地後跟正確次序收工:素材 → 裝備 → 紀錄 → 客戶;明白「現場 check 素材」點解係鐵律;識填任務版 flight log(飛行紀錄)。

    收工鐵律:柯打完成唔係落地嗰刻,係素材安全嗰刻。最貴嘅唔係隻機,係卡入面嘅嘢 —— 機可以再買,今日嘅日落買唔返。「唔 check 走人」等於白飛:返到屋企先發現條片 corrupt(檔案損壞),就要成隊人擇日再嚟。

    收工四步(次序唔准掉轉)

    1. 素材 check(未 check 唔准拆場):must-have 鏡頭逐條 playback(播返)確認;copy 一份去第二個儲存(手提 SSD / 電腦 / 後備卡)先算「安全」(隊上配手提 SSD,收場前一定要 copy:①SSD 插電腦 / 平板;②copy 成張卡過去;③隨機抽 2–3 條 playback 確認真係 copy 到;④卡保留唔 format —— 卡 + SSD 就係兩份;⑤兩份分開人拿、分開袋,一個人失單都唔會全冇。⚠️ copy 要時間,收場流程要預埋。);SD 卡由呢一刻起當寶保管。
    2. 裝備清點:用 checklist 逐格剔 —— 機、電池(數數目!)、槳、SD 卡、ND filters、遙控、叉電器。漏低一嚿電喺草地 = 蝕錢 + LiPo 安全隱患。電池熱住唔好即叉;長期唔用放 storage 電(Pack 01 第 3 課)🔧。
    3. Flight log:練習版加任務欄 —— 客戶、地點、架次、每嚿電用量、有冇 near-miss(險失事件)或異常(Pack 03 上報文化,任務日一樣適用)。呢份 log 唔係官僚嘢:下次報價、下次評估、出事調查全部靠佢。
    4. 向客戶現場交代,三句走人:「今日拍咗咩(對返 shot list)、幾時交到(確認 deliverable 日期)、下一步係咩」。有鏡頭走咗雞,而家講,唔好交片先俾客戶發現。
    🎮 互動練習 · 收工次序
    收工動作打亂晒 —— 按正確次序逐粒撳。有一粒係陷阱,任何時候撳佢都會出事。
      練習目標 + 完成標準 🔧 時限由負責人定

      模擬任務完結場景,獨立完成收工四步,觀察員計時 + 對 checklist,中間安排兩個干擾(客戶催走、有人問嘢)。完成標準:四步次序正確、素材確認兩份、裝備零漏、log 填齊、干擾冇打斷次序。

      ⚠️ 安全重點

      未確認素材有兩份之前,SD 卡唔准 format(格式化)、唔准重用。電池熱住唔叉、鼓咗即刻隔離 —— 趕頭趕命都唔可以跳。執嘢嗰陣最易鬆懈,圍觀者呢個時候埋嚟都係由 liaison 接手。

      Lesson 08

      交付基礎 — 命名、備份、保密

      學完呢課你識做咩用統一命名規則整理素材;講得出 3-2-1 備份原則同幾時先可以刪嘢;交付前行一次 review checklist,包括私隱同保密檢查。
      • 命名:三個月後嘅你要搵得返。建議格式:日期_客戶_地點_卡號(例:20260710_ABC公司_觀塘_C01)(團隊統一格式:日期_任務編號_客戶_卡號 —— 例:20260710_J042_ABC_C01。任務編號由負責人接單嗰陣編,寫喺 brief 上面,收工命名時照抄。咁樣素材、接單記錄、報價單三樣對得返,三個月後想搵返邊單都搵到。)。資料夾一單任務一個,入面分「RAW 素材 / 交付版 / 文件」。原則:任何人唔使問你都搵到嘢 —— 團隊資產,唔係個人記憶。
      • 3-2-1 備份原則。好似屋企鎖匙:自己一條、屋企人一條、一條放老家 —— 一個地方出事都仲入到屋。3 份 copy(原卡 + 兩份)、2 種媒介(電腦 + 外置硬碟,或硬碟 + 雲端)、1 份異地。團隊實際裝備:團隊實際配置:3 份 = 原卡 + 工作 SSD + 屋企硬碟;2 種媒介 = 現場 SSD + 屋企硬碟;1 份異地 = 屋企。唔上雲端(客戶素材唔出第三方,私隱風險最低)。⚠️ 實體異地最易失守嘅位:唔記得搬。所以「搬咗屋企硬碟」要當收工四步嘅一部分,未搬 = 未收工。。幾時可以刪 source / format 卡?跟保留政策(團隊保留期:交付後 1 年。一年之內唔准刪 —— 客戶隔幾個月回頭要多一個鏡頭係常態。卡就唔同:3-2-1 齊晒 + 逐條 playback 確認播得完,就可以 format 返用(卡係工具,唔係倉)。⚠️ 保留期長 = 私隱資料喺你手上耐,所以硬碟要上鎖 / 加密,唔好隨手擺。);底線:3-2-1 齊咗、客戶簽收咗,先可以講刪。
      • 交付前 review checklist:①每條檔案開得到播得完;②對返 deliverable 逐項剔;③私隱檢查 —— 畫面有冇清晰人面、車牌、屋內環境(處理方式:團隊做法:照交,但交付時要書面寫明 —— 「本批素材可能含可識別個人資料(人面、車牌、屋內環境),客戶發佈前須自行處理」。呢句要寫喺交付訊息 / email 入面,唔係口頭講。拿唔準嘅個案(例如明顯影到屋企入面、醫院、學校)先問負責人,唔好自己決定交定唔交。);④有冇拍多咗(影到隔籬地盤 / 私人地方嘅片段唔好交、唔好留);⑤交付方法同簽收(交付方式逐單由客戶揀,但流程係固定嘅:①接單評估嗰陣就要問實客戶要邊種交付(雲端連結 / 實體硬碟 / 客戶自己嘅系統)同埋邊個人收;②答案寫入 brief,唔靠記;③交付時連埋交付清單(逐項對返 deliverable)同私隱聲明;④要客戶文字回覆「收到、檔案正常」先算簽收,螢幕檔存住。冇問實交付方式 = brief 未完整 = 唔好開工。)。
      • 客戶資料保密。素材係客戶財產 —— 未經書面同意,唔准放上自己 IG / portfolio /畀朋友睇,「條片好靚咋嘛」唔係理由。簽咗 NDA 更加唔使講;冇簽都當有咁處理。團隊宣傳想用?經負責人向客戶攞書面同意(一律唔准。任務素材係客戶財產,放個人 IG / portfolio / 畀朋友睇 —— 全部唔准,「條片好靚咋嘛」唔係理由。團隊想攞嚟宣傳,由負責人向客戶攞書面同意,唔係隊員自己去問客戶。)。
