裝備保養與電池管理篇

Pack 01 教你認識隻機,Pack 02 教你飛得起 —— 呢個 pack 教你「養」。好多 incident(事故)唔係喺天上開始,係喺地上開始:螺絲喺地上已經鬆,電池喺上星期已經老。七課砌起一個循環:飛 → 查 → 記 → 排程 → 飛。(對象:完成 Pack 01–02 就讀得,唔使等 Pack 03/04。)

📌 成個 pack 嘅總綱,一句

部機唔會突然壞,只會突然俾你發現佢壞咗。保養就係將「突然發現」變返「早就知道」。

🚨 紅線:拆機、換件、firmware(韌體)更新 —— 教材只教「幾時要做、點解、搵邊個」,實際操作一律負責人示範 / 安排。隊員唔准自己 flash firmware、唔准改 parameter(飛行參數)。

呢個 pack 新出現嘅專業術語

只收新詞 —— LiPo、thermal runaway、storage charge、ESC、FC、gimbal、compass、calibration、hover check 呢啲舊詞,請翻返 Pack 01–03 嘅術語表。

術語淺白解釋
Preventive maintenance(預防性保養)唔係等壞先修,係定期檢查令佢冇機會壞 —— 好似洗牙 vs 牙痛先睇醫生
Cycle count(循環次數)充放一個完整來回 = 一個 cycle;係電池嘅「咪錶」—— 部車行咗幾多萬公里
Internal resistance / IR(內阻)電池內部「阻住電流」嘅程度 —— 內阻升高 = 老化訊號
Voltage sag(電壓驟降)電池一出力電壓突然跌一截 —— 老化電池特別明顯,好似老人家一行樓梯就喘
Smart battery(智能電池)自帶晶片識自我管理嘅電池 —— 有腦唔等於唔使你理,病歷照記
Consumable(消耗品)設計嚟「用舊就換」嘅部件,例如槳 —— 同車呔一樣,唔係壞先換係老先換
Bearing(軸承)摩打入面令佢順暢轉動嘅零件 —— 入沙或磨損會有沙聲、卡位手感

Firmware(韌體)機入面嘅系統軟件,好似手機嘅 iOS —— 成部機嘅「反射神經」全部係佢話事

Configuration management(機隊設定管理)成隊機嘅版本同設定由負責人統一管理 —— 唔會有「兩部望落一樣嘅機,行為唔一樣」
Desiccant(防潮珠)吸濕小包,餅乾盒嗰包「不可食用」—— 香港咁潮濕,佢係機箱常駐居民
Tag-out(標籤隔離)發現有問題嘅裝備即時掛停用標籤、攞出「可用池」,防止誤用 —— 課 7 詳教
Lesson 01

保養思維 — 部機喺地上嘅樣,就係佢喺天上嘅命

學完呢課你識做咩講得出「裝備狀態 = 飛行安全」點解係一條鏈;分得清「用完即棄」同「資產管理」兩種心態;講得出保養紀錄(病歷)幫團隊做到咩。
  • Incident 唔係喺天上開始。天上見到嘅係結果,原因一早喺地上:摩打半空停轉 —— 軸承上個月已經入沙;半空亂漂 —— 上次任務之後 compass 附近多咗嚿磁鐵配件;電量跳崖式跌 —— 嗰嚿電三個月前已經開始老。你喺地上肯花五分鐘,天上就少一個「點解會咁」。
  • 兩種心態:租車 vs 自己車。「用完即棄」(租車式):飛完攝埋一角、電池亂塞、唔妥「下次先算」—— 短期慳五分鐘,長期代價係裝備早死(錢)、任務日臨場撞板(時間)、帶病上天(安全)。「資產管理」(自己車式):每件裝備係會老化嘅資產 —— 狀態要知、要記、要管。無聊,但無聊嘅嘢做足,先輪到精彩嘅嘢發生。回報排優先:安全(最大)→ 錢 → 時間。
  • 病歷概念。醫生冇病歷,病人日日換醫生 —— 每次由零開始估。裝備一樣:邊嚿電跌電快、邊部機炒過機、邊個摩打換過 —— 冇人記低 = 判斷靠估。紀錄唔係官僚嘢,係令判斷有根據:今日呢嚿電出唔出到任務,唔係靠「我覺得佢 OK」,係靠佢份病歷。課 2 病歷卡 + 課 7 保養 log 係同一套系統。
  • 保養係邊個責任?人人有份。你今日飛嘅機,係尋日隊友保養完交畀你;你今日求其,聽日隊友承受。發現問題講出嚟係幫成隊人,唔係認衰 —— 報告問題永遠唔會俾人鬧,隱瞞問題先會。

⚠️ 安全重點

「睇落冇事」唔等於冇事 —— 檢查要有 checklist 同固定路線(課 3),唔係靠眼緣。隱瞞裝備問題係成套教材最嚴重犯規之一。保養狀態不明嘅裝備,一律當佢唔可以飛。

Lesson 02

LiPo 電池深度管理 — 電池係易燃資產,唔係配件

學完呢課你識做咩講得出 LiPo 生命週期三階段同徵兆;解釋 cycle count 同內阻做咩;識任務前後點處理電池;鼓包識行即時隔離程序;識填電池病歷卡。(接入門第 3 課,由「識同佢相處」升級做「識管佢一世」。)
  • 生命週期三階段:①新 —— 表現穩定;②老化 —— hover 時間短咗、跌電快咗、出力時 voltage sag(電壓驟降)明顯、發熱多過以前;③退役 —— 到標準就退,「仲用到」唔係留低嘅理由,老電池最鍾意喺半空先話你知佢唔得。好似職業運動員:唔係等斷腳先退役,係狀態落到唔可靠就要退。
  • 兩個「咪錶」:cycle count(充放一個來回 = 一個 cycle;smart battery 自己記,普通電靠病歷卡)—— 幾多 cycle 退役冇一條放諸四海嘅數,團隊參考線由負責人按型號定 🔧;內阻(IR) —— analogy 係水管生鏽:條管越舊內壁越嚡,同樣水壓出水越少仲會發熱。識得「內阻升緊 = 佢老緊」就夠。
  • 日常充放紀律:熱住唔叉(入門教過);叉電要有人喺附近、放唔易燃表面(團隊叉電規矩:①人唔喺場 = 唔准叉(包括「去咗買個包」呢啲);②唔准過夜叉;③電池要放防火袋 / 防火容器入面;④叉電台周圍唔准有紙、布、化學品);滿電唔好長放(老得快)—— 冇任務日子放 storage charge(半滿儲存);過低都唔好長放(過放風險)。Smart battery 嘅自動放電設定以廠方說明 + 負責人指引為準 🔧。
  • 出任務帶電池:每嚿獨立放(LiPo bag / 有間隔電池格);接頭遠離金屬(鎖匙散銀同電池同格 = 短路風險);編號認人(病歷卡靠佢);幾時叉滿由負責人定 🔧(原則:滿電時間越短越好,但一定夠任務用);搭飛機 —— 鋰電池民航規矩會變,一律以航空公司現行規定為準,行前負責人確認。
  • 退役標準(徵兆話事,唔係死數):①鼓包 —— 即時退役,冇「觀察中」;②外傷 / 入過水 —— 隔離,負責人評估;③內阻明顯升 / 跌電明顯快(病歷卡有紀錄先斷到症);④cycle count 到參考線 🔧;⑤過熱事故後。中間狀態「觀察中」:唔准出任務,分級用法由負責人定 🔧。
  • 棄置:唔准掉垃圾桶(火警 + 環境);教材唔教自行放電方法 —— 退役電處理由負責人安排(回收渠道:三步:①即刻隔離到防火容器;②貼標籤「壞電禁用」+ 日期;③交負責人統一處理。隊員唔准自行棄置、唔准自行放電)。
  • 電池病歷卡(每嚿電一張 / spreadsheet 一行):編號 | 型號 | 購入日期 | cycle count | 狀態(正常 / 觀察中 / 隔離退役)| 事故紀錄 | 備註 | 退役日期。

負責人準備三個「病人」(正常 / 老化徵兆 / 輕微鼓包),逐嚿判:出任務 / 淨練習 / 隔離退役,講理由,照住填病歷卡。完成標準:三嚿判斷正確;隔離程序講得齊(放邊、標籤寫咩、報邊個);病歷卡欄欄有嘢填。

⚠️ 安全重點

鼓包 = 即時隔離:放隔離位(防火袋 / 金屬箱,遠離易燃物)、寫標籤(咩事 / 邊日 / 邊個)、報負責人。Thermal runaway(電池自己燒起嚟,普通方法救唔熄)最常見導火線就係過充、外傷、鼓包照用 —— 你嘅隔離動作就係防火牆。嚟歷不明嘅電池唔准出任務。

Lesson 03

機身檢查與清潔 — 部機唔會投訴,你要主動問候佢

學完呢課你識做咩用固定路線做完整機身檢查;講得出清潔原則同三大禁忌;海邊 / 沙塵飛完識做對應處理;識五種「即刻停飛送檢」情況。

點解要固定路線?人眼好醒但好善忘 —— 次次行同一條路,先會發現「今日有樣嘢唔同咗」。香港特產提一提:鏡頭發霉 —— 潮濕放耐咗鏡片生霉菌,一發現即報負責人(課 6 教防潮)。

清潔原則 + 三大禁忌

  • 乾先於濕:先軟毛刷 / 吹波仔(air blower)吹走沙塵,先輪到抹。外殼用微濕布(扭到乾身);鏡頭一定用鏡頭布 + 清潔液 —— 衫角紙巾會劃花鍍膜,劃咗係永久。(用品清單:標準清潔包六件 —— 軟毛刷(刷沙塵)、吹波仔 air blower、超細纖維布 ×2(外殼用)、鏡頭布(淨係抹鏡頭)、鏡頭清潔液、棉花棒(接口同縫位)。隊上有提供,向負責人領)
  • 禁忌一:唔准用水沖 —— 除非廠方明寫防水等級,水 = electronics 殺手。
  • 禁忌二:唔准高壓氣直吹摩打 / 軸承 —— 你以為吹緊出嚟,其實將沙吹入更深。
  • 禁忌三:唔准亂用溶劑(天拿水、除銹噴劑)—— 蝕膠蝕漆滲電路。頑固污漬報負責人,唔好自己發明清潔方法。

海邊飛完點處理

鹽霧係隱形腐蝕劑 —— 部機冇落過水,空氣入面嘅鹽已經黐咗上機身同摩打。程序:①當日處理唔過夜:微濕布抹外殼再抹乾;②摩打罅隙用軟刷 + 吹波仔;③log 記低「海邊任務」(負責人要知部機食過鹹風);④有懷疑 → 停飛報負責人。沙塵環境同理,重點係摩打同 gimbal。

五種「即刻停飛送檢」

  1. 炒機 / 硬著陸之後 —— 就算外表完好,內傷係睇唔到嘅
  2. 飛行中異常震動或異響
  3. Gimbal 唔水平 / 畫面無故震
  4. 任何一個摩打明顯熱過其他
  5. 機臂 / 機身結構性裂紋

Lesson 04

摩打與槳 — 最平嘅零件,負責最貴嘅後果

學完呢課你識做咩講得出槳嘅退役標準;識用「聲、溫、手感」三招判斷摩打;講得出正反槳(CW / CCW)概念同裝錯後果;知道換件嘅「幾時、點解、搵邊個」。

點解呢課咁重要:槳係全機最平嘅部件,但槳一斷,成部機跟住落嚟 —— 連埋佢下面嘅人同財物。成部機嘅命,吊喺呢幾件最平嘅零件度,所以檢查標準全機最嚴。

槳:消耗品邏輯

見到以下任何一樣,支槳即棄:裂紋(幾幼都算)、崩口缺角、變形扭曲、槳根裂或鬆、撞過嘢(就算望落完好 —— 內部纖維可能已斷,望唔到)。兩條鐵律:

  1. 膠紙補槳 = 全教材最禁止動作之一。高速旋轉下,補過嘅槳係一件會甩出嚟嘅飛鏢。
  2. 退役槳要即場整爛先掉(剪爛 / 拗斷)—— 唔整爛,佢遲早混返入 spare(備用)堆,俾唔知情嘅隊友裝返上機。

摩打三徵兆:聲、溫、手感

招點做唔正常係點
聲飛行 / hover 時留心聽沙沙聲、唧唧聲、音調同平時唔同 = 軸承(bearing)可能入沙或磨損
溫落地後用手背輕試(唔好一手揸實,可能燙)重點唔係熱唔熱,係有冇一個明顯熱過其他 —— 四個摩打做緊同一樣嘢,一個特別熱 = 佢有事
手感斷電下用手指慢慢轉應該順滑冇卡位;有沙沙阻力、卡位 = 軸承問題

三樣有任何一樣 → 停飛、標籤、報負責人(課 7 流程)。唔准自己拆摩打 —— 拆完裝返嘅摩打冇人知得唔得,呢啲係負責人 / 送檢層次。

正反槳 CW / CCW + 換件授權

  • 四軸機兩支順時針(CW)、兩支逆時針(CCW),互相抵消自轉力 —— 位置一定要啱,裝錯一起飛即刻反艇,唔係「飛得差啲」。
  • 點認:槳上有標記(型號後綴 / 箭嘴 / 顏色圈),摩打座有對應標記 —— 你自己機型嘅認法由負責人示範 🔧。安裝實操:負責人親自示範 + 睇住你做先算學識(教材刻意唔用文字教安裝步驟)。你要識嘅係裝完自查:標記對位、上緊、輕拉唔甩;換咗槳一定記入 log。
  • 換件授權:件件裝備嘅安全裕度唔同 —— 槳裝錯即刻見,摩打 / ESC / 結構件裝錯可能飛咗三次先出事。授權表:✅ 隊員可以自己換:槳(裝完要自查 —— 標記對位、上緊、輕拉唔甩)、電池、SD 卡、線材。🔴 一律要負責人 / 送檢:摩打、ESC、結構件(機臂、腳架)、雲台、相機,同埋任何要拆機殼嘅嘢。⚠️ 換咗槳一定要記入 log。。原則:你唔肯定自己有冇授權 = 你冇授權。

撳「開始」檢查

Lesson 05

Firmware 與 Calibration 紀律 — 部機嘅腦,唔准亂郁

學完呢課你識做咩解釋 firmware(韌體)係咩、點解更新一定負責人統一安排;講得出「任務前唔升級」三個原因;分得清 calibration(校正)幾時做幾時唔好做;app 彈更新識行「唔撳 → 記低 → 報」。
  • Firmware 係咩:機入面嘅系統軟件,好似手機嘅 iOS —— 摩打點反應、failsafe 點行,成部機嘅「反射神經」全部佢話事。Parameter(參數)係入面嘅設定值 —— 好似手機設定選單,分別係撳錯嘅後果喺天上發生。
  • 點解唔准自己 flash / 更新 —— 三個原因:①一致性:你自己升咗一部,佢就同成個機隊「講緊唔同語言」,隊友仲以為部部一樣;②新版有時有新 bug:第一批更新嘅人係白老鼠,團隊唔做白老鼠;③更新可能 reset 設定、要求重新 calibrate —— 唔知就開飛,等於飛緊一部你唔識嘅機。呢個做法叫 configuration management(機隊設定管理):唔係信唔過你,係成隊機只可以有一個「真相版本」。
  • 任務前唔升級:更新萬一失敗 —— 部機聽朝用唔到,成單任務冧;就算成功 —— 行為可能變咗而你未試過,任務唔係試新嘢嘅地方。正確三步:唔撳 → screenshot / 記低版本號 → 報負責人。
  • 隊員可以:睇 version、記 version、報告 update 提示、跟負責人指示做已安排嘅更新。唔可以:撳 update / flash firmware、改任何 parameter、亂撳「reset / repair」類選項。
  • Calibration 幾時做:機 / app 明確要求、換咗好遠嘅地理位置飛、負責人指示。幾時唔好做:①金屬 / 磁場旁邊做 compass calibration(鐵欄、車頂、鋼筋地、天台機房側)—— 一次衰嘅 calibration 衰過唔做:你將「錯嘅參考」寫入部機;②趕時間亂做 —— calibration 係企定定慢慢做嘅嘢;③冇事日日做 —— 佢唔係拜神,做多啲唔會安全啲。IMU calibration 安排:只喺四個情況做:①部機自己報要求;②換咗結構件 / 拆過機;③飛行中出現無故飄移或者姿態奇怪;④溫差大(例:冷氣房搬出去露天暴曬)。做嘅人:PIC 或以上。做嘅地方:平面、冇震、冇磁性干擾。做完記入 log。❌ 唔准現場趕時間亂做 —— 趕住做出嚟嘅係錯參考,直接寫入部機。 🔧。任何 calibration 做完都要入 log。
🎮 互動練習 · 升唔升?
情境逐個彈出 —— 揀:裝 / 唔裝就算 / 唔裝 + 記低 + 報負責人。
撳「開始」
練習目標 + 完成標準 🔧 情境按團隊機型調整

三張情境卡書面作答:①任務前夜彈更新;②現場 compass 警告而你企喺鐵欄側;③隊友話「我幫你部機升咗級,新版好正」。完成標準:動作正確 + 每個講到一個原因;情境③要識上報 —— 擅自升級係 configuration 事故,唔係人情問題。

⚠️ 安全重點

唔准自己 flash firmware、唔准自己改 parameter —— 呢個係紅線,唔係建議。現場 compass 警告 ≠ 即場 calibrate:先諗環境 → 移位再試 → 仲有警告就報負責人。啱啱升完 firmware 嘅機,首飛當新機處理:負責人安排測試飛,唔准直出任務。

Lesson 06

裝備收納與運輸 — 部機瞓得好,先飛得好

學完呢課你識做咩講得出「一物一位」執箱原則;車程運輸識點擺;講得出香港兩大敵人(潮濕、高溫)嘅對策;識用出勤 checklist 執袋。
  • 一物一位:執箱唔係潔癖,係安全系統。每件嘢有固定位(foam 格 / 袋格):①執嘢快;②漏嘢即刻見 —— 個窿空咗就係漏咗,漏嘢偵測唔靠記性,靠個窿;③運輸互不相撞。Gimbal(雲台)上鎖 / 戴罩先入箱 —— 佢係全機最脆弱嘅部分,你聽唔到箱入面 gimbal 嘅慘叫。槳拆定唔拆 🔧 按機型,負責人示範。
  • 電池另放:佢係成箱嘢入面唯一一件「自己會出事」嘅嘢 —— LiPo bag 或專用格、接頭遠離金屬、唔好同機身迫埋一格。佢出事,你唔想佢連累成箱。
  • 車程運輸:箱要固定(綁帶 / 攝實);電池唔留焗車 —— 香港夏天車廂溫度好高,高溫係電池老化加速器,極端情況有安全風險,離車食晏電池帶埋走或放陰涼位 🔧 具體規矩由負責人定;淋濕咗嘅嘢抹乾晒先入箱 —— 密封箱 + 濕氣 = 焗霉神器。
  • 香港兩大敵人:潮濕 —— 防潮珠(desiccant)機箱常駐,飽和要換 🔧;長期存放防潮安排:兩條:①機箱常駐防潮珠,顏色變咗(飽和)即換或者焙乾;②每月開箱檢一次 —— 防潮珠顏色、鏡頭有冇霧 / 霉點、金屬位有冇銹。;鏡頭發霉就係防潮失守嘅結果。高溫 —— 裝備唔放窗邊、唔喺車尾長曬。
  • 出勤 checklist + 備件:出門前逐格剔,唔靠記性(同 Pack 02 起飛 checklist 同一個哲學)。備件基本盤:spare 槳 🔧 數量、spare SD 卡、各種線(遙控叉電線係最常漏嗰條)、防潮珠備用、電池數目 = 任務所需 + buffer 🔧。完整清單:
    【飛行】部機、遙控、電池(任務所需 + 1 套 buffer)　【槳】裝喺機上嗰套 + spare 一套　【存儲】SD 卡 ×2、手提 SSD　【線】遙控叉電線(最常漏嗰條)、電池叉電線、讀卡器、備用線　【防護】防潮珠備用、防火袋　【清潔】清潔包六件　【文件】brief、shot list、保單資料。
🎮 互動練習 · 執箱判官
執箱做法逐個彈出 —— 判斷:啱,定係會出事?
撳「開始」執箱
練習目標 + 完成標準 🔧 時限同抽走物品由負責人定

計時執箱:由「散裝狀態」執到「可出勤狀態」。負責人事先靜靜雞抽起一件嘢(例:遙控叉電線),睇學員幾時發現。完成標準:一物一位全齊、gimbal 有鎖 / 罩、電池獨立放好、發現被抽起嘅嘢並講得出發現機制(「呢個窿空咗」而唔係「我背得出清單」)。

⚠️ 安全重點

電池永遠唔留焗車 —— 呢條冇彈性。未抹乾、未降溫嘅裝備唔入密封箱。執箱見到有個位空咗 = 當漏咗:搵到 / 補到先出門,「應該喺度嘅」唔係答案。

Lesson 07

保養排程與紀錄 — 唔准帶病上天

學完呢課你識做咩講得出三級保養各做咩邊個做;識填保養 log;行到「發現 → 標籤隔離 → 報負責人」全流程;解釋「唔准帶病上天」點解冇例外。

三級保養(級數係深度,唔係日曆)

級幾時做咩邊個
1 · 每飛後每次任務 / 練習完即做課 3 路線快版、抹機、電池處置、填 log —— 幾分鐘嘅事當日用機嘅人
2 · 定期時數 / 架次或日曆計,邊樣先到就邊樣 🔧 間隔起點由負責人定課 3 全路線細做、螺絲逐粒過、槳逐支過、cycle count 對數、防潮珠檢查隊員(負責人指定)
3 · 深度負責人排程拆檢、送檢、firmware 統一安排、退役決定負責人主導

隊員喺第 3 級嘅角色:提供靠得住嘅 log —— 你嘅紀錄就係負責人嘅眼。

保養 log(同課 2 病歷卡係同一套系統)

每次保養一行:日期 | 機號 | 邊級保養 | 做咗咩 | 發現咩 | 邊個做 | 跟進。「冇發現」都要寫「冇異常」 —— 冇寫同冇異常係兩回事:冇寫 = 冇人知你有冇做過。載體同格式:Google Sheets,兩張表 —— ①電池病歷卡:電池號 | 入役日 | cycle | 狀態 | 備註;②保養 log:日期 | 機號 | 邊級保養 | 做咗咩 | 發現咩 | 邊個做 | 跟進。手機現場即填,自動備份、搵得返。連結向負責人攞。

發現問題三步:發現 → 標籤隔離 → 報負責人

  1. 發現 —— 任何人、任何時候:檢查中、飛行中、執箱時。
  2. 標籤隔離(tag-out) —— 即時攞出「可用池」:掛停用標籤寫齊三要素(咩問題 / 邊日 / 邊個發現);電池入防火袋隔離區、機掛「停飛」牌。點解要有形嘅標籤:口頭講「嗰部機有啲嘢」會俾人忘記、誤會、傳歪 —— 張標籤先係防止病裝備混返入可用池嘅真屏障。
  3. 報負責人 —— 講事實(咩徵兆 / 幾時 / 咩環境),唔使自己斷症。維修、送檢定退役,係負責人嘅決定。

唔准帶病上天

三句最危險嘅話:「今日單好緊要」、「應該冇事」、「上次都係咁,冇事喎」。帶病上天嘅數學:慳到嘅係一次改期;輸嘅可能係成部機 + 落地嗰下下面嘅人 —— 冇任何一單任務值呢條數。永遠有替代方案:後備機、改期、縮任務範圍。「冇替代方案」嘅答案係唔飛。

🎮 互動練習 · 隔離區逃走事件
一部標籤咗嘅機差啲被隊友攞返去用 —— 逐步行,搵出邊步失守、點補救。
    練習目標 + 完成標準 🔧 情境細節由負責人定

    全流程演習 —— 情境:「第 2 級保養發現機臂摺位有裂紋,而聽日有任務」。完成:填 log → 寫標籤(三要素)→ 隔離 → 口頭報告(講事實唔斷症)→ 講出聽日任務點算。完成標準:log 欄欄有嘢;標籤三要素齊;報告冇出現「應該冇事」;聽日方案係後備機 / 改期,唔係照飛。

    ⚠️ 安全重點

    標籤咗嘅裝備,唔准自己「試吓好返未」 —— 解除隔離只可以由負責人做。Log 求其填 = 冇填:下一手隊友係靠你嗰行字做安全判斷。帶病上天冇例外 —— 唔理今日單有幾大、客有幾惡。
