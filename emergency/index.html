Lesson 01

應急思維總綱 — Aviate, Navigate, Communicate

學完呢課你識做咩任何突發情境,即場用 A-N-C 次序講出應對步驟;每次起飛前帶隊講 60 秒 plan B(預案);panic(慌張)嗰刻識得點樣穩住自己。

點解要一條總綱。應急種類太多 —— 低電、失訊、GPS、compass、飛失 —— 冇可能逐樣背晒。所以航空界用一條萬用骨幹:Aviate, Navigate, Communicate(先控機、再定位、後通報)。好似急救嘅 ABC:醫護遇到咩傷都行同一條次序,唔使現場發明。

  • A — Aviate,先控機。部機失控一秒都唔可以冇人理。警告彈出、隊友嗌你、電話響 —— 全部排隊。GPS mode(自動定位)下鬆手 = hover(懸停),係你嘅定海神針 —— 但係如果部機已經跌落 ATTI(姿態模式,第 4 課),鬆手佢會飄。所以 Aviate 嘅真正意思唔係「鬆手」,係「唔好亂撳,有意識咁控住佢」。
  • N — Navigate,再定位。三條問題:部機喺邊?我喺邊?附近有咩危險(人、樓、馬路)?然後搵安全空間 —— hover、返航、定即刻落地。
  • C — Communicate,後通報。穩定咗先開口:「電量低,我返緊航」。口令跟團隊標準(Pack 02):起飛係嗌「Taking off!」→ 聽到「CLEAR」→ 先 arm;降落喺離地 10–20 米嗌「Landing!」→ 聽到「CLEAR」先繼續落。——但應急情況唔使等「CLEAR」:嗌一聲提場邊人就算,嗌唔切嘅話以控機優先,條命同控制權永遠排喺把口前面。(標準應急口令以團隊 OM 為準)

Panic 管理

出事嗰刻身體會出賣你:心跳加速、手震、tunnel vision(視野收窄到得返一個點)。三步:①深呼吸一下,俾個腦半秒重開機;②講出嚟 —— 大聲講「低電,返航」,講嘢會逼個腦由驚慌切返做嘢模式;③唔肯定下一步做咩,就唔好郁桿住(GPS mode 下 hover 等緊你)。好似學車死火:亂踩嘢仲弊過停一停諗一諗。

預案思維 — 起飛前 60 秒三問

  1. 而家要即刻落,落邊?
  2. 部機衝過嚟,人向邊邊走?
  3. 風由邊度嚟,部機冇力時會被推去邊?

Lesson 02

低電量應急

學完呢課你識做咩分得出 warning(第一級)同 critical(第二級)低電,講出各自正確反應;解釋點解頂風返航要預更多電;講出「電量焦慮」兩個極端點樣令人做錯決定。
  • 兩級複習 + 深化(接入門第 5 課)。Warning = 部機提你返航,你仲有得揀點樣返;critical = 部機可能自動降落,你已經冇得揀。好似架車:油燈著咗你揀油站,死火咗你冇得揀停邊。隊上返航門檻:30%(電量跌到 30% 前必須開始降落) —— 呢個數係死線,唔係參考。
  • Warning 響起嘅正確反應 —— 唔係「影埋呢個 shot 先」,係即刻做返航決策三問:①離 home point(起飛點)幾遠?②返程順風定頂風?③中途有冇備降點?三問答完就開始返航。
  • 頂風返航嘅陷阱。順風出去好化算,頂風返嚟食電多好多 —— 好似踩單車去程落斜返程上斜。螢幕嘅「仲飛到 X 分鐘」係按當前狀態估算,佢唔識預你等陣要頂風,所以計餘量一定要人腦補上風呢一項。隊上風速上限:以每部機說明書抗風上限為準 + margin(新手練習 5 m/s 以下)(接入門第 7 課 go / no-go 紀律)。
  • Critical 觸發之後 —— 唔好同 failsafe(自動保命機制)搏鬥。部機開始自動降落,你嘅工作變咗係幫佢落得安全:留意落點下面有冇人,同時嗌「Landing!」提場邊人(應急情況唔使等「CLEAR」回應)。自動降落期間可以介入幾多,唔同機型唔同 🔧 由負責人按隊上機型示範。
  • 電量焦慮陷阱(接 Pack 02 第 7 課)。兩個極端都危險:過度焦慮 —— 未到門檻已經慌,急急腳喺唔理想位置降落;掉以輕心 —— 「仲有 15% 咋喎」,但 15% 喺頂風加凍天(低溫 LiPo 鋰聚合物電池表現差)可能得返一半實用電量。正確心態:門檻之前照計劃飛,一到門檻即刻執行,唔拗、唔拖、唔賭。

Lesson 03

失訊應急

學完呢課你識做咩RC signal lost(遙控訊號斷)嗰刻,講出並做出正確首三步;起飛前指得出場地嘅訊號黑點;講出隊上失訊 failsafe 會點行。
  • 失訊有兩種,唔好撈亂。①圖傳 / 數傳斷(螢幕黑咗或者數據停咗)但遙控訊號仲喺度:你仲控到部機,靠肉眼 VLOS(目視飛行)飛返嚟 —— 呢個就係入門篇迫你練 VLOS 嘅原因。②RC link(遙控訊號)斷:你嘅指令去唔到部機,部機交俾 failsafe(自動保命機制)接手。
  • RC 失訊正確三步:①唔好狂撥桿 —— 部機收唔到,狂撥只係整定一堆亂命令,重新接通嗰刻部機突然收到反而危險;②望實部機,預佢行 failsafe —— 隊上設定係咩(hover 幾耐 → RTH 自動返航之類):一般設定為 RTH(Return to Home,自動返航),你知佢下一步做咩就唔會慌;③改善接收 —— 企高啲、行開障礙物、留意天線方向(天線好似支光管,光由側面出,筆尖嗰頭最弱,唔好用天線尖端直指部機)。
  • Failsafe 觸發後點配合。RTH 開始 = 爬升 → 直線返 home point → 降落。你嘅工作:望實返航線有冇障礙、通知隊友「部機自動返緊嚟」、訊號返嚟唔好即刻搶控 —— 接手前諗定接手做咩。
  • 預判黑點。大廈背後、金屬棚架 / 貨櫃旁、橋底、高壓電塔附近(EMI 電磁干擾)。起飛前問自己:「今日條航線邊一段會背住大廈?」答案寫入 plan B。

地面口述演練:督導無預警講「RC lost」,即刻收桿、口述部機接落嚟 30 秒會做咩(按隊上 failsafe 設定)、指出改善接收嘅移動方向。完成標準:三步齊 + 講中隊上 failsafe 實際行為 + 冇「狂撥桿」動作。

⚠️ 安全重點

失訊唔係即刻災難 —— failsafe 就係為呢一刻而設;最危險嘅係 pilot 心慌手快。真正風險係 RTH 返航線上有障礙,所以 home point 一定要設喺開揚位。圖傳斷唔等於失控 —— 分清邊條 link 斷咗先反應。

Lesson 04

GPS 失效 / 飄移應急

學完呢課你識做咩由螢幕同機身動態認出部機跌咗落 ATTI mode(姿態模式);講出 ATTI 下鬆手會發生咩事;講出樓宇間 GPS 差時嘅救機四步。
  • 幾時會發生。城市峽谷(兩邊高樓夾住,天空得返一條縫)、橋底、大型金屬旁 —— 衛星訊號被遮擋或反射,定位質素跌到某個位,飛控會自動放棄定位,部機由 GPS mode 降級落 ATTI mode。唔同機型叫法同行為有分別 🔧 隊上機型實際行為由負責人講解。
  • ATTI 係咩。部機只幫你保持水平,唔會定點。鬆手唔會停 —— 會保持慣性、隨風飄。Analogy:GPS mode 好似架車有自動泊車,ATTI 係普通車 —— 冇咗自動功能唔代表架車壞,只係要你自己揸。呢課最重要一句:ATTI 之下,鬆手唔等於 hover。
  • 徵兆:①螢幕 mode 字眼變咗;②衛星數目急跌;③部機開始慢慢自己漂移。
  • 救機四步(樓宇間):①Aviate —— 同自己講「而家係 ATTI」,細桿修正,唔好大桿(大桿喺窄位係自殺);②諗風 —— 風會將部機推向邊?背風嗰面最危險,因為部機會被推埋牆;③有得上就上 —— 頭頂開揚就慢慢增高離開峽谷,見到嘅天空多咗衛星通常返返嚟;④GPS 返嚟唔好即刻信 —— 等衛星數穩定先切返自動模式。
  • 另一種:GPS 飄移(drift / glitch)。GPS 冇死但「跳位」—— 部機以為自己喺第二度,喺 GPS mode 下會自己「修正」向錯誤方向走。見到部機無端端自己郁:唔好等,切手動或者即刻降落 🔧 邊個動作啱隊上機型由負責人決定並示範。

ATTI 唔係故障,係降級運作 —— 危險嘅唔係個 mode,係未練過嘅 pilot。未經負責人批准,隊員唔准自己喺空中試切 ATTI。樓宇間任務起飛前,必須有當日 plan B 降落點先准飛。

Lesson 05

Compass / 感應器異常

學完呢課你識做咩用自己嘅話描述 toilet bowl effect(馬桶效應);列出起飛前、起飛後各兩個 compass 異常徵兆;見到部機打圈,講出並執行正確即時應對。
  • Compass 做咩(複習入門第 1 課)。GPS 話俾部機知「你喺邊」,compass(電子指南針)話俾佢知「機頭指緊邊」—— 兩樣夾埋,部機先識得「向北飛」呢類指令。
  • Compass 錯會點。部機以為自己面向北,其實面向東 —— 每次自動「修正」位置都推錯方向,越修越歪,結果喺 GPS mode 下自己打圈,個圈越畫越大,好似馬桶沖水 —— 呢個就係 toilet bowl effect(馬桶效應)。Analogy:你矇住眼行直線,有人不停俾錯方向指示,你以為自己修正緊,其實兜緊圈。
  • 起飛前徵兆:①GCS(地面控制站)彈 compass error / 要求 calibration(校正);②地圖上部機箭嘴方向同實機機頭唔一致 —— 每次起飛前肉眼對一次(建議加入 pre-flight checklist,係咪正式加入由負責人決定);③起飛點係天台鋼筋地面、金屬棚、大鐵閘旁 —— 金屬同磁場係 compass 頭號敵人。
  • 起飛後徵兆:①hover check(低空懸停檢查)時部機慢慢畫圈;②分辨口訣:單向係風,打圈係 compass。
  • 即時應對。見到打圈:唔好撳 RTH!RTH(自動返航)一樣靠 compass 同 GPS 導航,compass 亂緊佢會一齊亂。正確做法:趁個圈仲細,直接原位降落;有能力兼獲授權嘅隊員可以切手動穩定佢 🔧 邊啲隊員授權切,由負責人定。
  • Calibration 紀律。企喺金屬旁邊 calibrate = 越校越錯。實際步驟按隊上機型 🔧 由負責人親自示範,教材唔提供逐步指令。

⚠️ 安全重點

Toilet bowl 初期好似風吹 —— 記住:單向係風,打圈係 compass。打緊圈唔好撳 RTH。金屬地面起飛出事係自己攞嚟 —— 起飛點揀位係第一道防線。

Lesson 06

Flyaway(飛失)處理

學完呢課你識做咩講出 flyaway 嘅定義;失控嗰刻 60 秒內做齊「五個即場動作」;講出搵機三步,同埋點解搵返部機都要上報。
  • 定義。Flyaway(飛失)= 部機唔再響應你嘅控制、離開預定飛行範圍。事後調查大部分 flyaway 都係 compass / GPS / 設定出事(即係第 4、5 課嘅嘢冇處理好)。所以:最好嘅 flyaway 應對,係前五課全部做足。
  • 即場五個動作:①眼唔好離開部機 —— 一睇唔到就好難再搵返,呢一刻你對眼比對手重要;②嗌出嚟:「部機失控,向北飛緊!」叫 spotter(觀察員)幫手跟蹤,佢跟機你控機;③試 RTH 掣 / 切 mode —— 有時切出 GPS mode 反而切斷咗個錯誤源頭,但呢招要練過先好用 🔧 邊啲隊員授權用由負責人定;④記低四樣嘢:方向、高度、大約速度、剩餘電量 —— 電量話俾你知佢最多仲飛得幾耐,即係你嘅搜索半徑;⑤唔好盲追 —— 追機衝出馬路,死過炒機。
  • 搵機三步:①LKP(最後已知位置):喺 GCS / app 攞最後座標,唔好熄 app、唔好亂撳 —— telemetry(遙測)紀錄係你張藏寶圖;②估落點範圍:LKP + 風向 + 剩餘飛行時間,劃個大約圈;③搜索都要安全守法:私人地方要問准先入,唔好爬棚爬樹冒險 —— 搵機唔可以製造第二單意外。
  • 事後上報。就算搵返部機、一啲花痕都冇,flyaway 一定要出 incident report(事故報告,第 8 課格式)—— 因為佢暴露咗一個未搵到嘅原因,唔報 = 下次原班人馬再嚟一次。落咗人哋物業、傷到人、整爛嘢 → 即刻跟第 7 課程序。
🎮 互動練習 · Flyaway 決策樹
部機飛失咗 —— 逐步揀你嘅做法。揀錯即刻見到後果,全程冇揀錯先過關。
撳「開始」進入情境
練習目標 + 完成標準 🔧 情境參數由負責人設定

決策演練:督導口述 flyaway 情境(方向、高度、電量),60 秒內口述做齊五個即場動作。完成標準:五個動作齊 + 冇危險選項 + 講得出搜索半徑點樣估。

⚠️ 安全重點

追機唔追命 —— 任何搵機動作唔可以令人身陷險。失控機電池遲早耗盡,佢一定會落地;你嘅工作係知佢大約落邊,唔係同佢鬥快。「搵返就當冇事」係最危險心態 —— 原因未搵到,炸彈仲喺度。

Lesson 07

炒機 / 墜機現場處理

學完呢課你識做咩按「人 → 火 → 機 → 證據」次序處理墜機現場;講出受損 LiPo(鋰聚合物電池)三條鐵律;傷人 / 損毀財物時講出即刻要做嘅兩件事,同點解唔可以私了。
  • 次序總綱:人 → 火 → 機 → 證據。好似車禍:你唔會第一時間檢查保險桿花咗冇,你先睇有冇人受傷。部機係錢,人係命。
  • 人。①有人受傷:急救行先,嚴重即 call 999;②部機跌緊落嚟嗰刻,你同隊友第一時間離開落點,唔好伸手接機;③落地後第一個動作:遙控 disarm / kill switch(緊急停槳)停晒摩打 🔧 隊上邊個掣由負責人示範。摩打未停晒,冇人埋身。
  • 火 —— 受損 LiPo(接入門第 3 課)。撞擊過嘅 LiPo 可能即刻冒煙,亦可能幾分鐘後先發作 —— thermal runaway(熱失控)一開始就停唔到。三條鐵律:①唔好徒手執起變形、發熱、冒煙嘅電池;②有得安全咁做先好用非易燃工具 / 防護手套將佢移離人群同易燃物,放喺石屎 / 泥地開揚位 🔧 隊上裝備由負責人確認;③觀察一段時間先好收起 🔧 觀察幾耐、用咩容器,由負責人定。補充:電池煙有毒,企上風位;真係起火,人員疏散優先,救唔到就唔好救。
  • 機 + 證據。未影相之前唔好執走殘骸(除非阻路或者有即時危險)。影四類相:①全景(部機同環境同一格);②近景損毀;③散落部件位置;④機身序號。Flight log(飛行紀錄)唔好刪、唔好覆寫 —— 佢係查原因嘅黑盒。log 格式同下載方法:DJI 飛行 App 電子紀錄(保養 log 另計一份)。
  • 責任(接入門第 6 課)。傷人或損毀他人財物,即刻做兩件事:①報警;②通知負責人,由負責人跟進 CAD(民航處)上報要求。CAD 上報程序(據 HK CAD 要求):有損毀 / 傷人 → 即報警 + email 民航處無人機辦公室 sua@cad.gov.hk;任何意外(無論有冇損毀 / 傷人)24 小時內書面詳報 CAD;如 CAD 要求,3 個曆日內補交詳情;保存意外 log 備查。同事主私下「傾掂數」唔等於處理咗 —— 第三者保險同法規責任都需要正式紀錄,私了反而令件事冇得補救。
🎮 互動練習 · 現場三秒決斷
墜機現場逐樣嘢彈出,三秒內決定:即刻用遙控停摩打 / call 999 / 用工具隔離唔徒手 / 影相之前唔好郁。
撳「開始」進入現場
練習目標 + 完成標準 🔧 道具、場景由負責人設計

現場模擬:用退役機 / 道具擺一個「墜機現場」,由頭做到尾:口述停摩打 → 隔離電池 → 影齊四類相 → 口頭向負責人報告。完成標準:次序啱(人→火→機→證據)、四類相齊、報告講齊人 / 火 / 機三方面狀態。

⚠️ 安全重點

槳未停,唔埋身。受損 LiPo 係計時炸彈 —— 處理咗火險,先處理其他嘢。傷人事故隱瞞唔報,係成個 pack 最嚴重紅線 —— 冇例外。

Lesson 08

應急演練 + 上報文化

學完呢課你識做咩帶隊做一次起飛前 60 秒 what-if brief(預案簡報);用 5W + 跟進框架寫一份完整 incident report(事故報告);向新隊員解釋 near-miss(險失事件)點解要報。
  • 點解要演練。應急反應唔係知識,係肌肉記憶 —— 頭 7 課嘅嘢,你唔喺地面練到熟,空中嗰 10 秒一定用唔出。Analogy:消防演習 —— 冇人等到真火先學走火通道。
  • 三層演練:①每次起飛前 60 秒 what-if brief(第 1 課三問)—— 成本最低,日日做;②定期圍枱演練 —— 圍埋用口行一次情境,本 pack 每課嘅練習就係現成材料;③督導實機演練 —— 模擬低電返航、督導下 ATTI hover 呢類 🔧 邊啲項目可以實機演、幾耐一次,由負責人排期並親自督導。
  • Near-miss 上報。差啲出事 = 系統送你一個免費教訓。冰山理論:一單真事故下面,通常瞓咗好多單冇人講嘅 near-miss —— 報咗,先有得喺變成事故之前攔截。團隊鐵律:上報唔會被罰。上報係幫全隊,瞞報先係害全隊。(呢條文化規矩,建議負責人喺隊會親口講一次,由上而下先立到。)
  • Report 唔係作文。寫事實,唔寫猜測;真係要寫猜測,標明「懷疑」;唔記得就寫「唔記得」—— 老作補完嘅 report 比冇 report 更毒,因為佢會誤導成隊人嘅改善方向。

⚠️ 安全重點
